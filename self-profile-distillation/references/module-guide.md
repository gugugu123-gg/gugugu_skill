# Module Guide

Distill the self-profile layer into four stable modules plus one overview.

## 00 overview

Purpose:
- summarize the current model version
- record the source range
- note major changes in the current pass
- link to the four modules

## 01 cognitive philosophy

Capture only stable worldview and judgment premises:
- ontology
- epistemology
- axiology
- ideology
- power relations

Rule:
- each item should point back to representative evidence or evidence groups

## 02 thinking style

Capture stable thinking patterns:
- core tensions
- analysis style
- reasoning paths
- decision style

Rule:
- separate recurring style from one-off opinions

## 03 language style

Capture stable expression patterns:
- rhetoric
- syntax
- characteristic vocabulary
- recurring phrases
- sentence habits
- overall tone

Rule:
- do not mix worldview claims into this module

## 04 behavioral traits

Capture stable action patterns:
- emotional intensity
- action orientation
- six-dimension radar with short written basis

Rule:
- the radar is a compact summary, not fake precision
