# Source Selection

Use these directories by default:

- `lite/`
- `insight/`
- `experience/01_Records/`
- `experience/02_People/`
- `experience/03_Projects/`
- `drafts & doing/`

Do not use `raw/` unless the user explicitly asks for it.

Selection rules:

- require a user-specified date range
- sort by `created`
- if `created` is missing, skip the note or list it as incomplete evidence
- treat explicit user-specified notes as supplemental evidence, not dominant evidence
- prefer already curated material over noisy material when the same topic appears in multiple places

Interpretation rules:

- look for repetition across notes
- look for continuity over time
- look for consistency across different note types
- ignore one-off emotional spikes unless they repeat over time
