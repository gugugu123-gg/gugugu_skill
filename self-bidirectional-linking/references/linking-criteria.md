# Linking Criteria

Only create reciprocal links when at least one of these is true:

- same topic with clearly different depth
- same project or subproject
- same unresolved problem or decision
- one note provides context, evidence, or continuation for the other
- one note names the same person, system, or object in a meaningful way
- one note is an obvious precursor or follow-up to the other

Avoid linking when:

- the overlap is only one generic word
- the relation cannot be explained in one short reason
- the note would be noisier rather than clearer after linking
- the relation exists only because both notes use the same framework vocabulary

Selection rule:

- prefer 1 to 5 strong links
- if there are many candidates, keep the most directly useful ones
