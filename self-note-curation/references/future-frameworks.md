# Curation Lens Index

Use these lenses to make the source structure visible:

- [ontology-lens.md](ontology-lens.md)
- [first-principles-lens.md](first-principles-lens.md)
- [polanyi-lens.md](polanyi-lens.md)

Use them together when the source has enough substance. Skip weak slots instead of filling them mechanically.

Shared rule:

- These lenses add stable structure to the curation result.
- They do not allow new claims, advice, or theory generation.
- Every filled slot must be traceable to the source.
- If the source does not support a slot, leave it blank or mark it as not explicit.
