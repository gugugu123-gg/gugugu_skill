# First Principles Lens

Use this lens to make the source's underlying assumptions and essentials more explicit.

Required checks:

- explicit assumptions
  - assumptions directly stated in the source
- implicit assumptions
  - assumptions that are necessary for the source logic to work and are strongly supported by the text
- minimum necessary elements
  - the smallest necessary parts repeatedly treated as indispensable in the source
- essence vs appearance
  - what the source treats as core versus what it treats as surface form, routine, or convention
- removable redundancy
  - steps, labels, or extras the source itself suggests may be unnecessary

Rules:
- This is still curation, not redesign.
- Do not invent a better solution than the source contains.
- If an implicit assumption is too uncertain, leave it out.
- Prefer the user's own distinctions over abstract reformulation.
