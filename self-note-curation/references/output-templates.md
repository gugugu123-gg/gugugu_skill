## Template Notes

- `## 正文` and `## 原文整理` should preserve source language and reasoning order.
- `## 可沉淀条目` is for durable items already present in the material, not new takeaways.
- `## 推理链` should preserve how the source moves from situation to judgment, question, or decision.
- `## 论据与支撑内容` should capture visible support, examples, or reasons from the source. If weak, write `- 源文未充分提供`.
- `## 遇到的问题 / 约束` and `## 处理方式 / 已形成的倾向` should stay source-backed.
- In `## 本体论拆解`, do not force all six slots to be filled.
- In `## 第一性原理拆解`, do not redesign the source into a better plan.
- In `## 判断与经验线索`, do not do mind-reading. If a signal is not explicit enough, mark it as not explicit.
- Replace `YYYY-MM-DD` with the note creation date and save the file under `项目/不知道怎么分类就随便放了/YYYY-MM-DD_Topic.md`.
- If the note comes from `raw/`, fill `原材料链接` and make sure the raw note links back under a processed-notes section.
- Fill `当日记录` only when a meaningful same-day record exists.
- Prefer original sentences. Avoid contrastive rewrite patterns unless the source itself clearly uses them.
