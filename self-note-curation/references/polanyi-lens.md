# Polanyi Lens

Use this lens to organize visible judgment signals in the source without doing psychology.

Required dimensions:

- Personal Knowledge
  - explicit experience, preference, background, values, or recurring stance
- Tacit Knowledge
  - places where the source clearly relies on practiced judgment, intuition, or felt sense
- From-to Structure
  - how specific details accumulate into a larger judgment, pattern, or conclusion
- Commitment
  - explicit long-term direction, sustained effort, path dependence, or refusal to switch lightly
- Discovery
  - explicit exploration, trial, search, iteration, or new finding

Rules:
- Do not infer motives or personality.
- Do not write "the user really means" or similar mind-reading claims.
- If tacit judgment is not clearly visible in the text, mark it as not explicit.
- Keep this layer close to the source language.
