
## Notes

- Keep the note concrete.
- If a section is not clear in the source, write `- 源文未明确展开`.
- `今日状态` is optional in substance but should be present in the template; if unsupported, write `- 源文未明确显示`.
- Keep `今日状态` short and source-grounded. It may describe mood, energy, tempo, or how the day seems to have gone, but should not become analysis or advice.
- Do not add a summary or takeaway section.
- Keep `想法` for the user's clearer thoughts, judgments, and summarized understanding.
- Use `灵感与线索` for intentions, promising angles, possible writing topics, research directions, reusable formulations, or explicit "remember this" signals from the source.
- Do not leave `灵感与线索` overly weak if the source clearly contains strong idea signals.
- Do not append the full original text by default.
- If the user explicitly asks to preserve the source text in the saved record, add it at the end under `## 原文`.
