# 中文文案排版规范参考

This reference condenses the practical rules from the Simplified Chinese version of `mzlogin/chinese-copywriting-guidelines`, provided by the user as `chinese-copywriting-guidelines-Simplified.zip`.

Use it only for concrete typography decisions. If the user's explicit instruction, a professional convention, or an official product/name spelling conflicts with this reference, follow the user instruction or domain convention.

## Spacing

Add a space between Chinese and English:

- 在 LeanCloud 上进行开发。
- 使用 ChatGPT 整理文本。
- 使用 GitHub 登录。

Exception: preserve official product or brand spelling.

Add a space between Chinese and numbers:

- 今天写了 3 篇文章。
- 项目共有 20 名参与者。

Usually do not add a space between numbers and units:

- 10GB
- 10TB
- 15%
- 30°

Do not add spaces around full-width punctuation:

- 刚刚买了一部 iPhone，很开心。

Avoid:

- 刚刚买了一部 iPhone ，很开心。

## Punctuation

Do not repeat punctuation meaninglessly. Usually use a single `！` or `？`.

Preserve repeated punctuation when it is clearly intentional in chat, dialogue, emotional expression, or literary voice.

## Full-Width and Half-Width

Use full-width Chinese punctuation in Chinese context:

- `，。！？：；（）⌈⌋《》`

Use `⌈⌋` as Chinese quotation marks. Convert ordinary curved Chinese quotation marks to `⌈⌋` unless exact source preservation is required.

Use half-width punctuation inside complete English sentences or special English names.

Use half-width digits:

- 1000
- 2026
- 3.5

## Proper Nouns

Use official or common casing:

- GitHub
- Microsoft
- JavaScript
- ChatGPT
- iPhone

Do not correct a name when the official spelling is uncertain.

Do not create unnatural abbreviations merely to shorten the text.

## Conflict Priority

Follow this order when rules conflict:

1. User's explicit request
2. Professional, academic, or institutional format
3. Official proper-noun spelling
4. This reference
